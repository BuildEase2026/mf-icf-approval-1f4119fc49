How it is worked out: pallets as per the Nudura take-off for each house type (2.4 x 2.4 m pallets). A 13.6 m artic takes 5 floor spots and an 18 t rigid 3; pallets stack in a spot up to 2,650 mm (the rigid's internal height to be confirmed with the haulier). Each block goes on the fewest vehicles, using rigids wherever they cover it. Pallets are stacked first-needed on top and vehicle 1 carries the accessory spot and the raft edge at the tail. Accessories cannot be sized accurately yet, so each block's accessories take one floor spot.

Sheets (per block): the pallet stack sheets show what is on every pallet - each pallet carries its block (e.g. B01 CUT-3) - with the block's ACCESSORY SPOT as the last sheet; the load plans show where each pallet and the accessory spot sit on each vehicle.
